# 02_README.md — DOKUMENTASI RESMI SISTEM SAFETITIP

Dokumentasi ini merujuk pada file utama [README.md](file:///d:/STARTUP-TIM_A/safetitip-app/README.md) di direktori root.

### Ringkasan Teknis:
- **Framework:** Next.js 16 (App Router), React 19, TypeScript.
- **Styling:** Tailwind CSS v4, Plus Jakarta Sans.
- **Penyimpanan:** Prisma ORM 5 + MySQL dengan Local Storage JSON Fallback (`data/bookings.json`).
- **Pengujian:** Jest Unit Tests (`npm test`).

### Cara Menjalankan:
```bash
npm install
npm test
npm run dev
```
Buka web browser pada `http://localhost:3000`.
